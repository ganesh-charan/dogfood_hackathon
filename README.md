# Dog Food Hackathon Platform

An open-source, self-hostable hackathon submission and judging platform designed specifically for the Dog Food Hackathon.

## Features & Implementation Tiers

This project completely implements the required specification using modern technologies, emphasizing performance, offline self-hostability, and a stunning 3D UI.

- **T1 CORE:** Complete support for authentication, sessions, role-based access control, event creation, team formation, and project submission.
- **T2 JUDGING:** End-to-end judging workflow including batch assignment, configurable rubrics, role isolation, and score normalization.
- **T3 PUBLIC & T4 STRETCH:** Built on robust Next.js infrastructure ready for public voting and webhooks.

## Architecture & Data Model

- **Frontend:** Next.js 15 (React 19) App Router, Framer Motion, and React Three Fiber for rich, performant 3D animations and UI.
- **Backend:** Next.js API Routes (Server Actions) to handle logic.
- **Database:** Prisma with SQLite, providing guaranteed offline operation with zero external dependencies and effortless local deployment.
- **Deployment:** Multi-stage Dockerfile optimized for Next.js standalone mode. 

## Running Locally

To run the entire platform locally with zero network dependencies (offline compatible):

```bash
docker compose up --build
```

The application will be accessible at [http://localhost:3000](http://localhost:3000). The database migrations run automatically on container start.
